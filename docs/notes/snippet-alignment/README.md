# C and instruction alignment

The course now pairs C operations with their related assembly instructions. The
change covers all 74 distinct C-backed programs used by the lessons, including
four generated by the local compiler. Assembly-only examples keep their existing
presentation.

The teaching links are separate from the original compiler line references.
Instruction order, recorded C, assembly text and original reference tags remain
unchanged. Compiler references are available in closed details. Stepping lights
the related C operation and the instruction that ran.

Simple examples show the complete C in paired rows. Reordered, repeated, unlinked
or multi-label examples retain the complete C separately and show paired source
excerpts in instruction order. Wide rows place C and assembly side by side; narrow
rows keep each source excerpt immediately above its instructions. Prediction
gates and comparison markings are preserved. During stepping, long listings use a
keyboard-accessible scroll region that follows the current operation.

- Independent [technical review](technical-review.md), including metadata transport,
  deletion identity, prediction gates and rendered regressions.
- One fresh browser reader per lesson, with a separate sceptic synthesis and
  checker follow-ups: [reader summary](reader-summary.md) and the individual reports.

The browser review found that source gaps could cross a function boundary after
deleting a return. Multi-label listings now use excerpts, keeping the full C
outside the function boxes. Review also found an undersized disclosure target;
it now has a 44-pixel minimum height and visible keyboard focus. A third finding
concerned long listings: the active operation could be far above the Next button.
The bounded stepping region keeps the current pair near the controls while
retaining scroll access to the whole listing. Its reveal logic accounts for the
part of that region actually visible in the browser. A final clarity note explains
that several linked C lines can represent combined operations or alternative
paths; highlighting them does not imply that all those statements execute together.

The authoring rules in `docs/authoring.md` now explain how to supply and review
source associations. Coverage, layout and interaction regression tests accompany
the change. The unrelated offline-status clarification already in the working
tree was preserved.
