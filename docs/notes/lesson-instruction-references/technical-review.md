- **“Every occurrence with the same mnemonic should share one URL.”** Rejected: immediate, register and extended operands differ; MOV, A32 and FP cases demonstrate why mnemonic-only categorisation is insufficient. The initial missing split-form finding survives this challenge because the actual operand-bearing introductions were absent from the linker’s per-lesson input.

The same lesson teaches register ORR and supplies both exact form references. No explicit operand-bearing ORR line is mislinked. All emitted explicit operand links were inspected.
- **“A32 inherited references enable A32 execution.”** Rejected: mapping is bibliography, TAUGHT and assembler support are unchanged, and the lesson explicitly calls A32 records static. A32 instruction URLs use DDI0597, while A64/FP URLs use DDI0602. The inherited lists intentionally include relevant sources from the surrounding split chapter; they do not assert that each listed instruction is newly taught on every child page.
- **“The retained old RET URL must change with BL.”** Rejected: its official body exists and describes the taught return form. A different edition alone is not evidence of a broken or incorrect reference.
- **“Linking hidden explanations reveals answers.”** Rejected for the implementation: only existing presentation Markdown is decorated, while disclosure and prediction gates still control rendering. Quiz question/options/hints/answers, challenge data, source code and programs are excluded. No reference result is generated or inserted into an assessment.
