# Workspace recovery

The execution environment was replaced before the first preview branch was pushed. Main remains at the previously merged flags lesson. The preview code has been recovered from the conversation and will be checkpointed remotely before further long runs.

Previously observed evidence, not a claim about this recovered build: the course-wide run passed phone and tablet routes for all80 lessons in both appearances/themes, and the first32 desktop/light lessons; its final status was not obtained. Independent reviews of register widths, memory and the shared shell found and verified fixes for a floating toolbar obscuring content, a clipped help popup and the skip link being covered by the compact header.

Five focused test failures were harness errors: four expected independent calculator scratch work to survive ordinary reload, whereas the existing calculator resets; one tried a second IPv4 origin against an IPv6-only server. The recovered harness checks scratch work across style switches, persisted challenge answers across reload, binds the test server to IPv4 and uses a dedicated storage canary for origin isolation. None requires a course model/storage change. The original failures are not passing results.
