These popup/skip checks also passed separately in Current for register widths and flags across all widths and themes, 16 states.

A separate normal build used `BASE_PATH=/ VITE_STYLE_PREVIEW=0 npm run build -w @al/course -- --outDir /tmp/assembly-review-normal`. It succeeded without writing to either course `dist` or `.style-preview-build`. At all four widths and both themes, register widths and flags ignored both `?style=new` and saved `style-preview=new`: no comparison controls, preview data attribute or preview wrapper appeared. Sixteen comparisons found Current's lesson x coordinate, width, font family, size, line height and colour equal to the normal build. Its y coordinate differed by exactly the reserved 60px toolbar.

A separate IPv4-bound read-only preview server on port 4446 supported a fresh service-worker check. Downloading for offline use gave scope `/`. ## Follow-up: outline selection at the page bottom

Confirmed a low-severity navigation/accessibility defect in the final pre-fix immutable preview from `/workspace/scratch/style-preview-deploy/dist`, served read-only on port 4452. Choosing the last register-width outline entry at 1280×1200 focuses “What you now know” and scrolls to the page bottom, but the shared scroll callback changes `aria-current="location"` back to “Four instructions”. The final h2 is at 235.2px (section edge 202.2px); scrollY and maximum scroll are both 3585px. The target cannot reach the observer's 180px threshold because scrolling is clamped. The selected state set by `go()` is therefore overwritten even though navigation and focus succeeded. A screenshot confirms the visible reflection section beside the incorrectly highlighted challenge entry.

The bounded check covered 32 combinations: register widths, `one-addition`, `twos-complement` and `c-integer-types`; widths 375/1280; heights 1000/1200; reduced motion on/off. After waiting one second for scrolling and the animation-frame observer, only the two register-width states at 1280×1200 had the mismatch, under both motion preferences. The other 30 matched their selected final entry. A small observer correction should recognise the final section when the viewport has reached the document bottom. No implementation was edited by this reviewer; correction and rebuilt-site verification remain pending.
